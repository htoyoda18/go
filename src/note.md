標準パッケージ・ランタイム・ビルドツール群

- archive
  - 圧縮・アーカイブファイル形式を扱う
- arena
  - Go 1.20 で導入された 実験的なアリーナ型メモリアロケータ
- bufio
  - バッファ付き I/O を提供する
- builtin
  - Go にあらかじめ組み込まれている 組み込み定義（型や関数） をまとめたパッケージ
- bytes
  - []byte（バイトスライス）操作用のユーティリティ
- cmd
  - Go ツールチェーンそのものを構成するコマンド群
- cmp
  - 型安全な比較関数を提供する小さなパッケージ
- compress
  - 圧縮アルゴリズムの実装を集めたパッケージ群
- container
  - クラシックなデータ構造をパッケージとして提供
- context
  - 処理のキャンセルやタイムアウト、リクエストスコープの値の受け渡し
- crypto
  - 暗号処理の基盤となるパッケージ群
- database
  - データベース関連のインターフェース定義を提供
- debug
  - デバッグや低レベル情報を扱う
- embed
  - Go プログラムに静的ファイルを埋め込む
- encoding
  - データのエンコード・デコードの共通インターフェース
- errors
  - エラーを生成・処理するための基本機能
- expvar
  - プログラムの内部状態を数値や文字列で公開し、主にデバッグやモニタリングに利用
- flag
  - コマンドライン引数のパース
- fmt
  - フォーマット付き入出力を提供
- go
  - Go コンパイラやツールチェイン内部で使われるパッケージ
  - go/ast
    - 抽象構文木
      - プログラムのソースコードを 木構造 で表現
- hash
  - ハッシュ関数の共通インターフェース
- html
  - HTML 関連の機能を提供
- image
  - 画像を扱う基本パッケージ
- index
  - インデックス作成や検索用のアルゴリズム
- internal
  - Goの内部利用専用パッケージ群
- io
  - 入出力の基本インターフェースを定義
- iter
  - Goにおけるイテレータを表現する
- log
  - シンプルなロギング機能を提供
- maps
  - ジェネリクス対応の map ユーティリティ関数
